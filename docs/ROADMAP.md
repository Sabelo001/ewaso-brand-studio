# Roadmap

## Version 1.0 (Current)

- Layout gallery with 19 branded layouts
- Full export pipeline (PNG/JPG/transparent/2×/4×)
- Asset library with local persistence
- Template system
- Studio settings (dark/light, canvas prefs)
- AI provider architecture (no API connections)
- Autosave and error recovery

## Version 1.1

- PDF export via `exportDesignPdf()`
- Cloud asset sync (`syncAssetsFromCloud()`)
- Undo/redo UI indicators
- Batch export for multiple aspect ratios

## Version 1.2 — AI Integration

- Connect OpenAI, Gemini, Claude providers
- API key management in settings
- Context-aware copy generation from layout + brand voice
- Layout suggestions based on content type

## Version 2.0

- User accounts and cloud template storage
- Team collaboration and shared brand kits
- Custom layout builder (admin only)
- Direct publish to social platforms
- Analytics on exported content

## Version 3.0

- Multi-page designs (carousels, stories sequences)
- Video export (animated layouts)
- Brand compliance checker
- White-label deployment for agency partners
